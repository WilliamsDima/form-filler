## Store listing

**Краткое описание** (подставляется из манифеста):
Заполняет веб-формы тестовыми данными из ваших шаблонов в один клик.

**Категория:** Developer Tools
**Язык:** русский

**Подробное описание:**

```
FormFill заполняет веб-формы тестовыми данными в один клик. Удобно разработчикам и тестировщикам, которые по сто раз в день заполняют одни и те же анкеты, регистрации и заявки.

КАК ЭТО РАБОТАЕТ
Напишите значения по одному на строку. FormFill сам поймёт, что это за данные, и разложит их по подходящим полям:
• ФИО — в поле «ФИО» или по отдельности в «Фамилию», «Имя», «Отчество»
• даты — в том числе в поля-календари
• e-mail, телефоны (и поля с масками), ссылки
• паспорт (серия и номер вместе или раздельно), код подразделения, водительское удостоверение, СНИЛС, ИНН
• адреса, числа, выпадающие списки

Смысл поля определяется по подписи, placeholder, атрибутам name, id, autocomplete и тексту рядом с полем. Значения вводятся так же, как при ручном вводе, поэтому формы на React, Vue и Angular их видят.

ПОЛНЫЙ КОНТРОЛЬ
• Бейдж у каждой строки шаблона показывает, как она распознана
• «Дата выдачи: 01.08.2020» — значение в поле с такой подписью
• «#promo: SALE» — значение в поле по CSS-селектору
• Переменные {{today}}, {{ts}}, {{rand:6}}, {{uuid}} — уникальные данные при каждом заполнении
• Отчёт: какое значение в какое поле попало

БЫСТРО
• Несколько шаблонов для разных сценариев
• Alt+Shift+F — заполнить без открытия попапа
• Правый клик → «Заполнить форму» → любой шаблон

ПРИВАТНО
Все данные хранятся только в вашем браузере. Расширение ничего не отправляет в интернет и получает доступ к странице только в момент, когда вы сами запускаете заполнение.

Исходный код: https://github.com/WilliamsDima/form-filler
```

## Privacy practices

**Single purpose description:**

```
Заполнение веб-форм на текущей странице значениями из шаблонов, которые пользователь создаёт в расширении.
```

**Обоснование разрешений:**

| Разрешение | Текст |
| --- | --- |
| activeTab | Нужен доступ к текущей вкладке, чтобы заполнить на ней форму, когда пользователь нажимает кнопку, горячую клавишу или пункт контекстного меню. Доступ ко всем сайтам не запрашивается. |
| scripting | Внедряет скрипт заполнения в текущую вкладку в момент заполнения по действию пользователя. |
| storage | Хранит шаблоны и настройки пользователя локально в браузере. |
| contextMenus | Добавляет пункт «Заполнить форму» с выбором шаблона в контекстное меню страницы. |

**Remote code:** No, I am not using remote code.

**Data usage:** не отмечать ни одного пункта — расширение не собирает данные пользователей.
Отметить все три подтверждения (не продаю данные, не использую их в посторонних целях, не использую для кредитоспособности).
